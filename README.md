🎓 «Знай-ка»: Интерактивное обучающее приложение для детей 👶
«Знай-ка» — это безопасное, простое и увлекательное обучающее десктопное приложение, разработанное специально для малышей 2–3 лет. Никакой рекламы, никаких скрытых платежей и интернета — только чистое обучение в игровой форме!

🚀 Основные возможности 
Обучение: Четыре категории карточек (Животные, Овощи, Фрукты, Цвета) с голосовым сопровождением. Ребенок нажимает — программа озвучивает.
Викторина: Режим проверки знаний с обратной связью. Правильно — «Молодец!», ошибка — вежливое «Попробуй ещё раз!».
Родительский контроль: Встроенный модуль статистики, который считает правильные и неправильные ответы, помогая отслеживать прогресс малыша.Безопасность: Приложение полностью автономно и работает без подключения к сети.

🛠 Технологический стек
Язык: Python 3.12
Библиотека: Pygame (отвечает за графику, обработку событий мыши и звук)
Среда разработки: Visual Studio Code

⚙️ Инструкция по установке
Шаг 1: Установи Python Если у тебя не установлен Python, скачай его с официального сайта.


💡 Будущие доработки. Проект продолжает развиваться! В планах:Конструктор контента: Загрузка новых категорий карточек из внешних файлов (JSON/CSV).
Система достижений: Виртуальные награды за серию правильных ответов.
Адаптивное управление: Поддержка сенсорных экранов и масштабируемые кнопки.
